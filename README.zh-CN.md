# 记忆宫殿 Memory Palace

[English](README.md)

一座为位置记忆法建造、可以在浏览器里漫游的三维记忆宫殿。它由古今各地真实类型的建筑组成，每一座都按它当年的实际用途来规划。
记忆位置就是建筑里原本就有的东西，放在它原本的位置，沿着路线编号。挂在上面的东西，只存在你的脑子里。

**在线浏览：<https://alexw6385.github.io/Memory-Palace/>**（电脑、手机都可以；中英双语，默认英文）

## 为什么要用真实的建筑

位置记忆法之所以有效，是因为一个你熟悉的地方本身就有顺序，不需要额外去记：先有大门才有庭院，祭坛在神龛前面，油灯挂在门边的墙上。
为某种用途设计的建筑，每个房间在哪里都有道理，每件东西在哪个房间也有道理。随机拼凑的房间和物件没有这种道理，也就挂不住记忆。

所以这里的每一处建筑都参照真实的例子，按真实的样子来规划，记忆位置就是里面真实存在的东西。

## 第一处：荷鲁斯神庙

仿埃及埃德富神庙（前 237—前 57 年），古埃及保存最完整的神庙。参观路线就是每日祭祀的路线：

1. **前导**：码头上神的圣船、羊首狮身像大道、路边祭亭。
2. **塔门**：刻着国王击杀敌人的两座塔楼、方尖碑、巨像、旗杆、大门。
3. **献祭庭院**：最后一处露天的地方，有净手石盆、建庙碑、荷鲁斯隼像、大祭坛。
4. **大厅**：前厅（十八根柱子，每个柱头是不同的植物，附藏书室和更衣室）、显现大厅（实验室、宝库、尼罗河室、储藏室）、
   通往屋顶的楼梯所在的供奉厅、九神厅。每进一厅，地面高一级，屋顶低一些，光线也暗一些。
5. **圣殿**：圣船与花岗岩神龛，四周是秘仪回廊，九个小堂供奉荷鲁斯家族与神话中的众神。
6. **神庙周边**：刻着荷鲁斯与塞特神话的外围回廊、圣湖、圣甲虫与尼罗河水位计。

共 47 个记忆位置。看着某个位置时会显示它的编号和名字；按 **N** / **B** 沿路线前后移动。

**操作**：W A S D 走、拖动转头、Shift 奔跑、`N` / `B` 下一个 / 上一个位置、`M` 地图、`P` 地点；手机上左下摇杆走、拖动屏幕转头。
「地点」列出所有房间和位置，点一下就能过去。

## 本地运行

```bash
pip install -e ".[dev]"
python -m palace build      # 布局 → web/data/world.json
python -m palace serve      # http://127.0.0.1:8000
```
