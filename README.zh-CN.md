# 记忆宫殿

[English](README.md)

一个可以自由行走的写实 3D **建筑**世界：各个时代、各个文明、各种风格的建筑，每一座都依照真实的实例建造，按照它当年真正的使用方式规划，有真实的材料、光与影，以及符合其文明与年代的音乐。

**进入：<https://alexw6385.github.io/Memory-Palace/>** —— 电脑或手机，需要支持 WebGPU 的浏览器（Chrome、Edge、Safari 26）。界面可切换中文与英文。

这个名字有两层意思。这些建筑是各个文明的记忆；而一座规划良好的建筑本身就给了每个房间、每件物品一个位置和顺序——这正是古典“记忆宫殿”所需要的。但这里是一个用来行走的世界，不是学习工具：没有笔记、没有标记、没有路线。建筑若有动线，由建筑本身来表达。

## 现在可以参观

- **埃德富荷鲁斯神庙**（托勒密埃及，前237—前57年），古埃及保存最完整的神庙，按真实尺度建造：带旗杆与花岗岩荷鲁斯隼像的塔门、三面 32 根柱子的庭院、18 根柱子的前厅、显现大厅、供奉厅、九神厅、安放内克塔内布二世花岗岩神龛与圣船的至圣所、秘仪回廊及其九座小堂、围墙内的外回廊——每进一厅，地面更高、屋顶更低、光线更暗。神庙坐落在河岸边，棕榈环绕。

- **帕特农神庙**（雅典，前447—前432年），立于卫城岩丘之上：完整的多立克柱式、山花、环绕金象牙雅典娜像的双层柱廊与像前水池，以及有四根爱奥尼柱的后殿宝库。
- **万神殿**（罗马，约公元114—128年）：十六根花岗岩柱的门廊、青铜大门、彩色大理石的圆厅，以及其上的藻井穹顶与敞开的天眼。
- **圆顶清真寺（岩石圆顶）**（耶路撒冷，691/692年）：岩石上方的金色穹顶，大理石与马赛克的八角形外墙，两圈回廊与镀金拱廊；立于高台之上，旁有锁链圆顶，四周是橄榄林和带小圆顶的石屋城镇。
- **巴黎圣礼拜堂**（1242—1248年）：彩绘柱子的下层礼拜堂，以及其上的上层礼拜堂——十五扇彩色玻璃窗围成的“玻璃笼”，蓝底金星的拱顶，彩色阳光洒落在地面上；周围是塞纳河畔木骨架房屋的城镇。
- **圣索菲亚大教堂**（君士坦丁堡，532—537年，穹顶562年重建）：架在帆拱上、底部环绕四十扇窗的大穹顶，半穹顶与半圆殿，楼廊，金色马赛克与大理石，圣坛与读经台，内外前廊与中庭——坐落在临水山丘上、满是瓦顶房屋的城市里。

每座建筑都坐落在自己的**区域**里——同一条河谷中的一块盆地，有各自的地形、地面、植物、聚落与道路，也有自己的天空：一天中的时刻、雾霭，以及边走边变的天气（飘过地面的云影、沙尘、雨与湿地、风）。区域之间的山脊上有山口，道路由此相连。

接下来会为每个主要建筑传统各建一座（见 [DESIGN.md](DESIGN.md) §11）。

## 操作

W A S D 或方向键行走，鼠标环顾（点击画面锁定鼠标），Shift 奔跑，M 打开地图，Esc 暂停。手机上：左手拇指拖动摇杆行走，在其他地方拖动环顾。加载完成后世界会自动打开，点击画面开始环顾。在地图上点击任意位置即可前往，点击建筑可到达其入口。

## 如何制作

- **先写考据档案。** 每座建筑都依据 [`docs/buildings/`](docs/buildings) 中有出处的档案建造（真实实例、平面与尺寸、结构、用途、材料、装饰、采光、音乐；并区分来源明确记载的内容与我们的推断）。世界布局见 [`docs/world.md`](docs/world.md)。
- **平面是数据，外观是代码。** 建筑的平面以米为单位，由墙、门洞、地面、屋顶、柱子与物件组成（`src/buildings/<id>/plan.js`），再由该文明可复用的建筑语汇绘制（`src/styles/<文明>/`：柱与柱头、圆凸线脚与凹弧檐口、塔门、门框、雕像）。
- **渲染：** three.js WebGPU（无 WebGPU 时退回 WebGL 2），与每面墙真实砌层对齐的程序化 PBR 材质，级联阴影，GTAO，泛光，AgX 色调映射，以及人眼明暗适应。
- **烘焙光照：** 间接光（天空、石面反射的阳光、油灯）离线光线追踪成每座建筑的辐照度体积（`tools/bake.mjs` → `data/gi/`），随建筑一起加载。
- **地景：** 整条河谷由同一个高度函数描述，地形分块并按距离细化，在 Worker 中生成；地面覆盖与植被按区域布置；树木、棕榈与草实例化绘制，带细节层级并随风摇动（`src/world/`、`src/engine/flora/`）。
- **音乐：** 依据每座建筑的乐谱在浏览器中实时合成（`src/buildings/<id>/music.js`），从露天庭院走进大厅、再到至圣所，音乐随之变化。

纯静态 ES 模块，没有构建步骤，也没有服务器；three.js 从 CDN 加载。

## 开发

```bash
npm install                      # 仅开发工具：playwright、three、three-mesh-bvh
npm run serve                    # http://127.0.0.1:8000
npm run check                    # 平面检查：可行走性、每个房间可达、门洞连通、无悬空物件
npm run bake -- edfu             # 烘焙建筑的间接光 → data/gi/edfu.bin
npm run shot -- --building edfu  # 在 tools/viewpoints.json 的固定视点截图 → shots/
npm run budget                   # 加载与体积预算
npm test
```

每次推送到 `master` 都会运行检查并发布到 GitHub Pages。
