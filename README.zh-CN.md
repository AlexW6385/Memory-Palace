# 记忆宫殿 Memory Palace

[English](README.md)

一座为位置记忆法建造、可以在浏览器里漫游的三维城市。它只提供位置：沿着清晰路线、摆满各不相同物件的房间。
挂在上面的东西，只存在你的脑子里。

**在线浏览：<https://alexw6385.github.io/memory-palace/>**（电脑、手机都可以；中英双语，默认英文）

## 方法

位置记忆法是最古老的记忆术：把要记的每样东西变成一个夸张、生动的画面，放在一条熟悉路线上的一个个位置里——
第一个台座上的钟，第二个台座上的月亮。回忆时，在这里或在脑中按同一路线再走一遍，画面都在原处。

这座城就是为此建的：

- **位置多**：中心一座宫殿，周围八栋建筑——天文台塔、图书馆、剧院、港口、集市、铸造厂、大教堂、植物温室，
  共 74 个房间、444 个位置。
- **互不相同**：每个位置上的物件都不一样，每个房间有自己的风格、颜色和光线（书架林立的图书馆、赌场、鱼市、
  地下墓室……），位置之间不会混淆。
- **路线清楚**：每栋楼把房间串成一条路线；房间里的位置沿过道左右交替排列。
- **永远不变**：城市由 [content/city.json](content/city.json) 确定性生成。以后只会在空地上加新楼，已有的房间和物件
  永远不动。
- **什么都不记录**：没有账号、没有笔记、不做追踪，页面只记得你上次站在哪里。

**操作**：W A S D 走、拖动转头、Shift 奔跑、`M` 地图、`P` 地点；手机上左下摇杆走、拖动屏幕转头。
「地点」列出所有建筑和房间，点一下就能过去。

## 本地运行

```bash
pip install -e ".[dev]"
python -m palace build      # 布局 → web/data/world.json
python -m palace serve      # http://127.0.0.1:8000
```

结构、开发和部署见英文版 README。
