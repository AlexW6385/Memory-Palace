# Instructions for agents

Read `DESIGN.md` in full before doing anything, and work within it. It is the brief for this project: what it is, what it is not, the priorities, the rules, the phases, and what you may decide yourself. At the end of every session update its status section (§11) and append any decision you made to its decisions log (§10).

Every building is built from a sourced dossier in `docs/buildings/`; write the dossier first. Use only CC0/MIT assets and list them in `ASSETS.md`.

Commits are authored as the repository owner, Alex Wang <alex119122114@gmail.com>, with no AI co-author or session trailers; commit messages in English. Keep repository text (code, docs, commits) in English; the site UI is bilingual with English default.
